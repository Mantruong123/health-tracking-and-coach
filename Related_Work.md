# 2. Related Work

AI-assisted fitness tracking and health coaching have moved through distinct generations of methods. The earliest systems relied on hand-crafted sensor algorithms and manual data entry, shifting gradually toward computer vision and end-to-end deep learning. Surveys in mobile health (mHealth) highlight this shift from hardware-dependent engineering towards vision-based AI, noting that visual occlusion, cross-platform performance, and real-time latency remain persistent challenges regardless of the chosen method.

The first generation treated exercise tracking as a sensor-based or manual logging problem. Engineers extracted movement data from wearable sensors—accelerometers and gyroscopes for motion, heart rate monitors for exertion—and fed them to classical pattern recognition algorithms or simple threshold-based counters. These systems were power-efficient and ran easily on modest hardware, but they were restrictive: a tracking logic that worked for a wristband often failed to capture full-body posture, and the user had to purchase specialized hardware. Furthermore, manual logging applications required users to proactively input their diets and workouts, leading to high friction and low retention.

Benchmark datasets have shaped the shift toward vision. Datasets like COCO (Common Objects in Context) and MPII Human Pose provided hundreds of thousands of annotated images, acting as the foundation for training robust human pose estimation models. Both are common test beds, but neither was exclusively designed for high-speed, dynamic fitness movements in diverse home environments.

Deep learning for fitness tracking moved from heavy convolutional neural networks (CNNs) processing static images, to RNNs and LSTMs for temporal sequence modeling, and then to optimized mobile architectures. Research shows that pairing a lightweight convolutional model with spatial heuristics can match offline, server-bound tracking systems in real time. Frameworks like Google's ML Kit and MediaPipe set out the basic recipe for mobile vision, demonstrating that skeletal landmark detection can reliably run on consumer smartphones, while other studies use temporal sequence analysis to evaluate form over an entire repetition.

The second generation replaced wearable hardware with representation learning via computer vision. Heavy CNNs like OpenPose could read joint coordinates from multi-person camera frames, while recurrent networks modeled how a user's posture changed over time. These models set new records on large computer vision benchmarks, but they required significant computational power, often mandating that video frames be sent to a cloud server. This approach not only introduced network latency—destroying the real-time feedback loop—but also raised significant privacy concerns for users exercising in their homes.

Two broad approaches run through this history. Wearable sensors are cheap to compute and privacy-preserving, but they only capture movement without understanding posture. End-to-end deep vision models in the cloud learn rich spatial features and score higher on form correction, yet they require heavy compute and constant internet access. On-device machine learning sits between the two: the expensive training happens offline, and the optimized model can then be reused locally on the mobile device. This project takes that middle path.

Three challenges cut across these generations and remain open. The first is visual occlusion: body parts are often blocked by equipment or the user's own body, making landmark detection noisy. The second is camera placement and environmental variation, since a model trained on idealized, front-facing fitness videos usually drops sharply in accuracy when dealing with arbitrary phone angles or poor lighting in a bedroom. The third is personalization, as generic workout tracking fails to adapt to a user's unique metabolic metrics (BMI, BMR, TDEE) and real-time progress. This project responds to all three, with robust on-device pose tracking that tolerates varied environments, an honestly evaluated set of core exercises, and integrated AI-driven nutritional and workout personalization.

Large-scale computer vision research changed how human motion is represented. OpenPose showed that part affinity fields could yield highly accurate spatial encodings. Google ML Kit Pose Detection, built upon the BlazePose topology, gives solid, high-fidelity 33-point skeletal landmarks optimized entirely for mobile edge devices. Its representations differ from heavier cloud models by prioritizing speed and efficiency over multi-person contextual tracking. Furthermore, the integration of advanced recommendation algorithms allows health applications to move beyond basic tracking into dynamic, personalized coaching.

The mechanism matters for the design here. Cloud-based models transfer video frames over the network, introducing latency that disrupts real-time workout feedback. ML Kit specializes its architecture for mobile CPUs and GPUs, so its landmark space reflects immediate, frame-by-frame spatial structure. The backend API widens the objective to include nutritional intelligence and user management, which makes its features complementary to the mobile tracking. That complementarity is the basis for the multi-tiered architecture used in this project.

For fitness tracking specifically, earlier applications provided basic timers and static video tutorials, confirming interactive, real-time feedback as an active challenge in mHealth. More recently, complex multimodal systems have applied 3D depth cameras (like Microsoft Kinect) or LIDAR to achieve high accuracy, which represents the strongest technological result but is highly inaccessible to the average user.

Against this background, the present work is deliberately pragmatic. Rather than proposing a brand-new pose estimation neural network architecture from scratch, it asks how far the careful engineering of existing, state-of-the-art components—Google ML Kit for vision, FastAPI for backend intelligence, Flutter for cross-platform delivery, and a robust payment gateway—can be pushed to create a cohesive home fitness ecosystem. Heavier cloud-based models represent the alternative route of learning new dimensional representations; the two approaches are separated by the trade-off between absolute accuracy and accessible, real-time privacy.
